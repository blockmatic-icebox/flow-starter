# External invocation is read-only for canvas

External invocation is follow-on work under [PRODUCT.md](../../PRODUCT.md). When implemented, the same eve agent serves browser workspace users and external coding clients, but server tool policy limits external callers to cited answers and optional validated json-render specs. They cannot mutate browser canvases or infer selection from an open session. Machine credentials and channel auth enforce that boundary independently of prompts. See [ARCHITECTURE.md](../../ARCHITECTURE.md) §3.
