# Initiative — CareBook (clinic booking v1)

**Status:** In progress

## Accepted decisions

- **Patient cancellation:** 24-hour window before appointment start (clinic-local time).
- **Out of v1:** waitlist, instant cancellation without policy review, insurance billing, video visits.

## Open (Plan)

- Provider hours configuration (provider vs clinic admin).
- Cancellation edge cases: staff override, no-show vs late cancel.
