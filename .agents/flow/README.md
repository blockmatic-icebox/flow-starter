# Flow

Concise shared conventions for the starter, using [Matt Pocock's skills](https://github.com/mattpocock/skills) as the primary workflow.

Read [flow.md](flow.md) for current conventions and root [AGENTS.md](../../AGENTS.md) for project pointers.

- [Matt workflow guide](../../README.md#matt-pocock-workflow): choose the relevant skill and apply project conventions.
- [/f-extract](../skills/f-extract/SKILL.md): adapt a reusable capability from another branch.
- [/f-ship](../skills/f-ship/SKILL.md): check, commit, push an approved branch, observe deployment and verify behavior.

GitHub Issues tracks work. [docs/decisions/](../../docs/decisions/) is the single active decision sequence for product, design and engineering. Older Factory decisions and extended guides remain historical reference, loaded only when relevant; they do not impose the retired orchestration process.
