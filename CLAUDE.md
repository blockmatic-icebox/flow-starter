# Project Rules

## Prompt Logging

The committed `prompts.txt` is empty. A fresh clone starts with no entries. Do not backfill earlier sessions into the file.

Every time you receive a new instruction or prompt in this working copy, append it to `prompts.txt` in the project root with a timestamp (ISO 8601) and a brief summary of what you did in response. Create the file if it doesn't exist. Keep this log updated throughout all sessions after clone.
