# Product

This repository is an **agentic**, **MCP-first**, and **API-first** application starter.

It exists so you can prototype interfaces and agent workflows quickly: describe a UI in natural language, get a declarative OpenUI composition rendered with shadcn components and synthetic data, and expose the same capability over MCP and Eve tools. Postgres tooling is included for when you add real persistence; the GenUI demo does not require a populated database.

See [ARCHITECTURE.md](ARCHITECTURE.md) for verified commands and boundaries, [DESIGN.md](DESIGN.md) for the default shadcn visual system, and [docs/specs/001-lean-agentic-starter.md](docs/specs/001-lean-agentic-starter.md) for the starter specification.
